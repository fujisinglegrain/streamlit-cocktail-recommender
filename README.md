# 🍸 프라이빗 바텐더 (Private Bartender)

Python과 Streamlit을 활용한 **맞춤형 칵테일 추천 및 관리 대시보드 웹 애플리케이션**입니다.  
사용자의 취향(알코올 도수, 단맛/드라이함, 기주 등)을 기반으로 최적의 칵테일을 추천하며,  
관리자 모드를 통해 레시피를 실시간으로 관리할 수 있습니다.

## 🌟 주요 기능

### 1. 사용자 맞춤형 추천 (퀴즈 기반)
- 스무고개 형태의 질문을 통해 취향 분석  
- 디포즈 가이드 / 오마카세 테스트 제공  
- 추천 결과와 함께 추천 이유 설명  

### 2. 로그인 및 세션 관리
- 회원가입 및 로그인 기능  
- 사용자별 상태 유지 (취기 진행도, 마신 기록)  

### 3. 관리자 대시보드 (CRUD)
- `admin` 계정 접속 시  
  - 칵테일 조회  
  - 삭제  
  - 신규 추가  

### 4. 캐싱(Caching) 기능
- `@st.cache_data`를 활용한 데이터 캐싱  
- 데이터 변경 시 캐시 초기화 후 즉시 반영

## 🧠 데이터셋 구성

- 본 프로젝트의 데이터는 디포즈 가이드(https://www.diffordsguide.com/)를 참고하여 수치적인 정보를 구성하였고,  
  맛과 향에 대한 부분은 관련 서적(칵테일 테크닉 | 우에다 카즈오)을 기반으로 직접 정리하였습니다.  
- 또한 일부 부족하거나 존재하지 않는 데이터는 LLM을 활용하여 보완하여 직접 구축하였습니다.  

- 전체 데이터는 JSON 기반의 커스텀 칵테일 데이터셋으로 구성되어 있습니다.  
- 각 칵테일은 기주(base), 그룹(group), 맛(category), 향(flavor), 설명(descriptor) 등의 태그를 가지고 있습니다.  
- 이러한 다중 태그 구조를 기반으로, 사용자의 선택에 따라 가중치를 부여하여 보다 정밀한 추천이 가능하도록 설계했습니다.  
- 또한 레시피, 도수(ABV), 이미지 경로까지 포함하여 실제 서비스 형태와 유사하게 구현했습니다.  

- 추가로 **alcohol_score**는 단순히 도수(ABV)가 높다고 증가하는 값이 아니라,  
  쉐이킹이나 스터 등 제조 과정에서 발생하는 희석 정도를 반영하여  
  사용자가 실제로 체감하는 ‘알코올 부즈감’을 기준으로 설계된 지표입니다.  

- 각 질문은 고유한 `id`를 가지며, `priority`와 `role` 속성과 함께 사용되어  
  단순한 순차 진행이 아닌 조건 기반의 동적 질문 흐름을 구성하도록 설계했습니다.  

- 또한 데이터는 사전에 정의된 정규 워딩(group, base, category, flavor, descriptor)을 기준으로만 추가되도록 설계하여,  
  데이터 일관성과 추천 정확도를 유지하도록 하였습니다.  

- 현재 데이터셋은 약 **20개 이상의 질문**과 약 **60개의 칵테일**로 구성되어 있습니다.  

- 이미지 데이터의 경우, 그룹을 표현하는 이미지는 저작권 문제가 없는 무료 이미지를 사용하였으며,  
  일부 시그니처 칵테일 이미지는 직접 촬영한 사진을 활용하여 구성하였습니다.
